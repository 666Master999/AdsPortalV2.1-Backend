Краткое описание
=================

`AdsPortalV2.1` — простой бэкенд для доски объявлений на .NET 10 (C# 14).

Быстрый старт
-------------

- Требования: .NET 10 SDK
- Клонировать репозиторий и перейти в папку проекта:
  - `cd AdsPortalV2.1`
- Восстановить зависимости и запустить:
  - `dotnet restore`
  - `dotnet build`
  - `dotnet run`

Конфигурация
-------------

Настройки приложения и строка подключения находятся в `appsettings.json`.
Для работы БД используйте миграции EF Core (`dotnet ef migrations` / `dotnet ef database update`).

Контроллеры и API
------------------

Основные контроллеры находятся в папке `Controllers` и обеспечивают функции авторизации, управления объявлениями, чат, избранное и т.д.
